# Kickstarter Campaign Analysis Dashboard

## Project Overview
This project presents an interactive Power BI dashboard designed to analyze Kickstarter crowdfunding campaign performance. It provides insights into funding trends, campaign performance, and project success rates.

## Project Objective
The objective of this project is to analyze Kickstarter campaign data and understand funding patterns, project performance, and factors related to campaign success.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Visualization
- Data Analysis

## Key Features
- Interactive dashboard visualization
- Campaign performance analysis
- Funding trend analysis
- Project success rate analysis
- Visual exploration of campaign data
